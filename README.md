# مصحف — اقرأ، استمع، تدبّر

تطبيق مفتوح المصدر للقرآن الكريم يعمل على **الويب (PWA)** و**سطح المكتب (ويندوز / ماك / لينكس)** و**الجوال (أندرويد / iOS)** من كود واحد، مبني على تصميم الفيجما الخاص بالمشروع.

> عمل وقفي — نسأل الله أن يتقبله خالصًا لوجهه الكريم.

**🌐 جرّبه الآن:** https://osa98.github.io/mushaf/
**⬇️ تحميل التطبيق (ويندوز · ماك · لينكس · أندرويد):** [صفحة الإصدارات](https://github.com/OSA98/mushaf/releases/latest)

## التشغيل محليًا

```bash
npm install
npm run dev          # http://localhost:5173
```

## البناء والنشر

### ١) الويب (PWA)
```bash
npm run build        # الناتج في dist/ — ارفعه على أي استضافة ثابتة
```
النشر التلقائي على **GitHub Pages**: ارفع المشروع على GitHub، ثم من *Settings → Pages* اختر *GitHub Actions*. كل دفعة إلى `main` تنشر الموقع (`.github/workflows/web.yml`).
ويمكن أيضًا استخدام Netlify أو Vercel أو Cloudflare Pages (أمر البناء `npm run build` ومجلد النشر `dist`).

### ٢) سطح المكتب (Electron)
```bash
npm run electron:start   # تجربة
npm run electron:build   # إنشاء المثبّت في release/
```
**للنشر:** غيّر رقم `version` في `package.json` (مثلًا من `1.0.1` إلى `1.0.2`) وارفع التعديل على `main` — سيُنشأ إصدار جديد تلقائيًا ويُبنى فيه ويندوز (مثبّت + نسخة محمولة) وماك ولينكس وملف APK للأندرويد.

### ٣) الجوال (Capacitor)
```bash
npm run android   # يفتح Android Studio ← Build ← Generate Signed Bundle (AAB) لرفعه على Google Play
npm run ios       # يفتح Xcode (على جهاز ماك) ← Product ← Archive لرفعه على App Store
```
قبل النشر غيّر `appId` في `capacitor.config.ts` و`package.json` إلى معرّف خاص بك (مثل `com.yourname.mushaf`).

## التخصيص

- **الاسم والروابط**: `src/config.ts` ← `BRAND` (اسم التطبيق، روابط المتاجر بعد النشر، البريد).
- **الألوان والخطوط**: `src/styles/global.css` (مأخوذة من ملف الفيجما).
- **القراء والتفاسير والترجمات**: `src/config.ts`.
- **الأيقونات**: `npm run icons` (من `src/assets/logo.svg`)، وللجوال: `npx @capacitor/assets generate`.
- **بيانات المصحف**: `npm run data` يعيد توليد `public/data` من [quran-data-kfgqpc](https://github.com/thetruetruth/quran-data-kfgqpc) (ضع المسار في `KFGQPC_DIR`).

## هيكل المشروع

```
src/
  pages/        الشاشات (الرئيسية، المصحف، الفهرس، المكتبة، المحفوظات، الإعدادات، البحث، القراء، الإذاعة، الختمة، المواقيت، صفحة الموقع)
  components/   الشريط السفلي، القائمة العلوية، مشغل الصوت، لوحة التفسير، الأيقونات
  lib/          تحميل بيانات المصحف، الصوت، الواجهات البرمجية، البحث
  store/        الإعدادات وبيانات المستخدم (محفوظة محليًا)
public/data     نصوص الروايات الثماني (JSON) + فهرس البحث
public/fonts    خطوط مجمع الملك فهد لكل رواية
electron/       غلاف تطبيق سطح المكتب
android/ ios/   مشاريع الجوال (Capacitor)
```

## المصادر والتراخيص

- نصوص المصحف وخطوطه: **مجمع الملك فهد لطباعة المصحف الشريف** ([qurancomplex.gov.sa](https://qurancomplex.gov.sa/techquran/dev/)) عبر مستودع quran-data-kfgqpc — يُرجى الالتزام بشروط المجمع (عدم تعديل النص).
- بيانات الأجزاء والأحزاب والسجدات وتحويل الترقيم بين الروايات: [quran-meta](https://github.com/quran-center/quran-meta) (MIT).
- التفاسير والترجمات: [AlQuran Cloud API](https://alquran.cloud/api).
- التلاوات والإذاعات: [mp3quran.net](https://mp3quran.net/api) و[Islamic Network CDN](https://cdn.islamic.network).
- مواقيت الصلاة: [adhan-js](https://github.com/batoulapps/adhan-js) (MIT).
- خط الواجهة: IBM Plex Sans Arabic (OFL).
